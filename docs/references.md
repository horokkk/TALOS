# 참고 자료 (교수님 제공, last updated 2026.05.09)

## Simulation / Models
- **RIGYD** https://rigyd.com/ — 이미지/3D 객체/설명을 시뮬레이션 에셋으로 변환. Gazebo, Isaac Sim 등 지원.
- **Gazebo Fuel** https://app.gazebosim.org/fuel/models — Gazebo 월드/모델 다운로드
- **Objaverse** https://objaverse.allenai.org/ — 대규모 3D 객체 데이터셋
- **Mixamo** https://www.mixamo.com/ — Gazebo 액터용 애니메이션 3D 캐릭터
